Where we are

Thirty squads run systems that ten SRE people actually understand

12critical shared services
100+APIs consumed by IPB, PBA and GVA tenants

Every squad already has an AI agent in their IDE. What none of them have is the operational context that makes it useful — what a service depends on, what breaks it, what the last five incidents taught us, and what they are allowed to touch.

So the agent writes confident code against a system it cannot see, the defect surfaces in production, and the escalation lands on the same on-call rota it always did. Adoption of the tool went up. Toil did not go down.

The constraint is not tooling. It is context — and context does not scale by hiring.

The move

Ship the context, not another tool

The kit is a repository, not a product. Operational knowledge is written once, reviewed like code, and rendered into whatever agent the engineer is already running.

One

Canonical layer

AGENTS.md plus a skill per operational task. Single source of truth, versioned, pull-requested.

Two

Generated adapters

Each surface gets a thin generated adapter. Nobody hand-maintains a second copy of the rules.

Three

Existing surfaces

Cline today, Copilot when Cline reaches end of life. Same content — only the adapter changes.

Nothing to procure, nothing to migrate, and exactly one place to fix a wrong answer.

Why it is safe here

Two properties, both structural rather than promised

Blast radius

The agent cannot write to production

Write-capable operations are blocked by the platform's deny hook before the request reaches the model. Not a policy the model is asked to respect, and not a setting an engineer can toggle mid-session.

If the deny hook is missing, the session does not start.

People risk

Individual performance cannot be reconstructed

The kit emits counts, durations, hashes and categorical values against a stable pseudonym, with no mapping retained anywhere. Any engineer can inspect the exact payload before it leaves.

The measurement design was built for squads, so squad is the smallest unit that exists.

Asked whether we can see one engineer's numbers, the honest answer is that the system cannot produce them.
